# Kivy App

Dieses Projekt zeigt eine einfache grafische Benutzeroberfläche mit Kivy.

## Projektstruktur
- Notebook (.ipynb): Erklärung und Dokumentation
- app.py: ausführbare Kivy-Anwendung

## Voraussetzungen
- Python 3
- Kivy

## Installation
pip install kivy

## Start
python app.py funktioniert nicht,
deswegen im Terminal eingeben: python3 05-Kivy/app.py
